# Validador de Frontend

**Objetivo:** Garantizar un frontend de alta calidad visual, interactiva y responsiva.

**Acciones:**
1. Verifica que todo nuevo diseño siga los lineamientos de UI/UX modernos (o las reglas específicas del proyecto).
2. Asegúrate de mantener una estructura limpia y modular.
3. Valida que el frontend interactúe correctamente con las APIs correspondientes.
