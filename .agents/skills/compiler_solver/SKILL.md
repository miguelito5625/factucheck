# Compilador y Solucionador de Errores

**Objetivo:** Entregar siempre código funcional y libre de errores de sintaxis o compilación.

**Acciones:**
1. Ejecuta los comandos de compilación o linters correspondientes del proyecto.
2. Si encuentras errores, analízalos y aplica las correcciones necesarias de manera autónoma.
3. Solo notifica al usuario cuando el código compile correctamente o si encuentras un error crítico que requiera su decisión.
